# Посмотри в окно
Проектная работа курса "Фронтенд-разработка". Это приложение, которое показывает видео "из окна" в разных городах. Видео можно искать по городу и времени суток.
HTML и JavaScript были готовы заранее, задача была написать CSS по макету в Figma.

## Что сделано
* лейаут страницы на Flexbox;
* видео и превью подогнаны под размеры через `object-fit`;
* обрезка длинных названий (`text-overflow: ellipsis`) и описаний (`line-clamp`);
* кастомные чекбоксы на псевдоэлементах и стилизованное текстовое поле;
* состояния `:hover`, `:active` и `:focus-visible` у кнопок, карточек и элементов формы;
* позиционирование прелоадеров.

## Технологии
* HTML5
* CSS3 (Flexbox, псевдоклассы `:has()` и `:focus-visible`)
* БЭМ

## Как запустить
Открыть `index.html` в браузере.
